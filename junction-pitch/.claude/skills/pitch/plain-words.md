# Plain words for spoken pitches

Spoken English for a big room, a non-native speaker, under stress. Check every script line against this list.

## Sentence rules
- One idea per sentence. Most sentences under 12 words.
- Subject, verb, object. No "which" chains, no brackets, no semicolons.
- Numbers: round them and say them the way people say them. "One in four orders", not "24.7 percent". "About two million euros", not "1,947,300 euros". Keep the exact figure on the slide.
- Say the unit every time ("12 minutes per order"), never a bare number.
- No abbreviations the jury must decode (FTE → "full-time workers", SKU → "product", CX → "customer service"), unless the partner's rubric uses the word: then say it once and explain it.
- The user is a person: "a picker in a grocery warehouse", not "stakeholders". Use a persona name only if core.md gives one (and then say "think of <name>", so nobody hears it as a real interview).

## Swap these
| Avoid | Say |
|---|---|
| utilise, leverage | use |
| approximately | about |
| facilitate, enable | help, let |
| in order to | to |
| a significant number of | many / the number |
| revolutionary, disruptive, game-changing, seamless, cutting-edge, next-generation, synergy, paradigm, ecosystem, holistic, robust | drop it, or show it in the demo |
| AI-powered, intelligent solution | say what it does: "it predicts", "it warns" |
| end-to-end | from the order to the doorstep (say the real span) |
| leveraging data-driven insights | it learns from <which data> |
| we are passionate about | drop it |

## Hard to say under stress (replace)
| Hard | Easier |
|---|---|
| statistically, particularly, specifically | drop it, or "in fact" |
| approximately, simultaneously | about, at the same time |
| infrastructure | systems |
| probabilistic, heterogeneous, comprehensive | likely, mixed, full |
| anonymised, anonymous | "no names stored" |
| entrepreneurship | starting a company |
| sixth, twelfths, months' | rephrase ("month six") |
| long runs of s-sounds ("six sensors sense...") | rephrase |
| any word you tripped on in rehearsal | replace it; do not practise it |

Partner and product names: ask the partner rep how they say their name, and write it phonetically in a `> ` note once.
